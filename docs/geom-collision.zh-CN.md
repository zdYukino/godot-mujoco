# geom 碰撞设置

在左侧选择 geom，展开 Inspector 的 **MJCF 碰撞**。每个 geom 独立选择碰撞表示，最终由同一 MuJoCo 世界计算接触。

| 几何 | 碰撞表示与参数 |
|---|---|
| mesh | **凸包**：`maxhullvert` 为“不限”（-1）或至少 4；写入标准 MJCF mesh 资产 |
| mesh | **SDF**：默认深度由引擎决定（当前 6），自定义为 3–8 |
| sphere / box / capsule / cylinder / ellipsoid / plane / hfield | 原生表示，只读；保留原有几何参数编辑方式 |

SDF 深度旁的黄色 **!** 可悬浮查看说明：深度仅保存在 Godot 作者数据中，不随 MJCF 导出。单独重新载入导出的 XML 会使用 MuJoCo 默认深度。凸包/SDF 类型、凸包顶点上限、有效世界参数和依赖文件正常导出，不生成深度 sidecar。

“有效碰撞”显示实际编译得到的 SDF 深度与单元数；草稿尚未通过编译时标明“上次有效”。共享一个 mesh 的多个 geom 会在修改精度或缩放时派生独立资产，继续引用同一原始网格文件。复制、重命名、撤销、保存和重开均保留各自设置。

选择 World，在同名分组中设置六项全局参数：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| nativeccd | 开 | 开启 GJK/EPA；关闭时使用 libccd/MPR |
| multiccd | 开 | 多接触点检测；不是时域连续防穿透 |
| ccd_iterations | 35 | 凸检测迭代上限 |
| ccd_tolerance | 1e-6 | 凸检测容差 |
| sdf_iterations | 10 | SDF 迭代数 |
| sdf_initpoints | 40 | SDF 初始搜索点数 |

这六项以 World 为准，应用到模型预览、共享世界和 MJCF 导出；导入源中显式设置的世界值会保留。重力、时间步、积分器、求解器及其他全局选项仍须一致。geom 的“世界检测策略”旁 **→** 可跳到所属 World。

SDF 支持静态网格和带 joint 的动态 body。网格须有限、非退化、闭合且绕序一致；尺寸检查使用相对尺度，允许毫米级零件。空间查询还要求 octree 根半轴大于 2e-6，根范围满足 `abs(center)+half <= 1024`。

默认预算是每网格 20,000 个三角形、每网格最多 500,000 个 octree 单元、每世界合计 2,000,000 个单元。前后两项可通过项目设置 `mujoco/authoring/sdf_max_triangles_per_mesh`、`mujoco/authoring/sdf_max_cells_per_world` 调整；500,000 是固定查询支持上限。预算使用实际网格统计，不将纹理内存算作 SDF 单元。它们不是峰值内存限制；编译超时仍默认为 120 秒并可取消。

失败时保留作者草稿、撤销记录和上次有效预览，运行物理保留并暂停，当前设计验证成功前无法继续。可修正设置、撤销，或使用“恢复上次有效设计”。Ctrl+S 仍可保存未完成的草稿。

模型导入现在仅接受 MJCF XML。旧模型资源、`.gmj.json`、升级按钮、自动转换与旧实时编辑协议均已移除；请从 MJCF 源文件重新导入。
