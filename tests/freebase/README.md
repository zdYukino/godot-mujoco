# G1 自由基座验收

固定 Linux、Godot 4.7.2 .NET、MuJoCo 3.16；上游 Unitree 资产保持只读。自由基座显式选择 relaxed 模式，不提供站立或行走控制。

- `OUT=/新目录 bash tests/freebase/run.sh`：真实自由基座、异步编译/生命周期、重置、脚底接触、材料摩擦系数和普通 Godot 障碍物碰撞回归。
- `DISPLAY=:1 XAUTHORITY=... OUT=/新目录 bash tests/freebase/run_gui.sh`：先跑无界面回归，再通过限定测试 PID 的 X11 输入操作实际组件。依赖系统 X11/XTEST 与 Python Pillow，不需要缺失的旧 mouse_acceptance 模块。
- 添加 `GMJ_FREEBASE_NATIVE=1` 运行真实 MuJoCo 原生后端；该大型 G1 夹具显式使用既有可配置 192 MiB 模型预算。原生未真正启动、GL 错误或重载后丢失原生渲染均失败。

GUI 覆盖暂停时游戏 UI 继续更新、Step9 精确 0.018 秒、原版 Run/Pause、手动快照、失败重载保留旧世界与成功重载重新绑定。F11 仅提供 Godot Tools；不通过隐藏旧控制器触发操作。

低摩擦、高摩擦、障碍物夹具仅派生保存的模型资源。作者资源保存姿态和控制，不保存瞬时 qvel；夹具从实际零速度开始，使用相同的已保存水平重力 `[2, 0, -9.8]` 作为刺激。真实 Step N 执行 1000 步（2 秒），采集脚底接触、实际求解器接触摩擦系数、模型质量加权质心和骨盆轨迹、穿透深度、有限值及警告。无控铰接机器人会倾倒，摩擦变化不保证骨盆或质心水平位移单调；验收确认接触系数确实匹配材料并保留原始轨迹。障碍物夹具必须观察到 G1 与普通 StaticBody3D 的接触对。

Fixture 按钮只选择候选保存场景，重载通过产品控件和事务边界执行；观测脚本不直接修改正在步进的 model/data。截图、状态、测量和日志保存在 OUT。非零退出、超时、脚本/GL 错误和泄漏均失败。该范围不宣称修复已有冷导入平台限制。
