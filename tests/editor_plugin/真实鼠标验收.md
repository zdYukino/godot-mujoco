# 真实鼠标选择回归

需要 X11/XTEST、Python python-xlib、ImageMagick `import`、固定官方 Godot 4.7.2 .NET 与已构建扩展。显示区域至少1600×1000，不要在自动化过程中移动鼠标或覆盖测试窗口。

```sh
DISPLAY=:91 GODOT_BIN=/path/to/godot OUT=/absolute/new/output bash tests/editor_plugin/run_mouse.sh
```

探针仅建立确定的 MJCF/球体夹具、观测控件坐标/选中标记/物理快照、滚动到目标控件及退出。测试通过 XTEST 发送真正鼠标和键盘事件，不调用 Tree 的 item_selected 信号或 select 方法模拟目标点击。保存、打开、Apply、Discard、undo/redo也由真实输入驱动。

覆盖pending时点击上方arm、下方sphere、重复节点和当前hinge，移开鼠标后检查实际高亮、同一草稿控件与编译XML不变；Discard后允许切换、无效JSON保留状态、Apply/重复Apply、Ctrl+Z/Ctrl+Shift+Z及保存重开。`mouse_acceptance.py 新观测目录 已保存文档.gmj.json` 可用于第二个编辑器进程的恢复检查；该进程需用相同probe参数启动。测试输出截图、JSON物理状态、逐项结果和原始日志。任何ERROR/泄漏、脚本异常或非零退出均失败。

本机容器缺少 Vulkan ICD 时，即使 Compatibility 正常渲染，编辑器也会报告 Vulkan surface ERROR。应修复宿主驱动配置，不豁免日志。无GPU云端可使用系统发行版的官方 Mesa Lavapipe：通过标准 `VK_DRIVER_FILES` 指向其ICD JSON、`LD_LIBRARY_PATH` 指向提取的驱动目录；正常工作站优先使用管理员已安装的驱动。此配置不是引擎补丁，不能据此宣称其他宿主或冷导入稳定性通过。
